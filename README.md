# I Plant

A gardening app that maps your yard, estimates sun across it, tracks your plants, and reminds you when to prune, fertilize and cover them.

Built with React Native (Expo) for iPhone and Android.

## What works so far

- Step 1: enter your address (or use your current location) and see your yard on a satellite map.

## Try it on your phone

1. Install **Expo Go** from the App Store or Google Play.
2. Install **Node.js** (LTS) on your computer from https://nodejs.org.
3. In a terminal:
   ```bash
   git clone https://github.com/tampham98/i-plant-app.git
   cd i-plant-app
   npm install
   npx expo start
   ```
4. Scan the QR code that appears: on iPhone with the Camera app, on Android from inside Expo Go. Your phone and computer need to be on the same Wi-Fi.
